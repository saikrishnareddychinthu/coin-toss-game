# 🪙 Coin Toss Game

A simple and interactive **Coin Toss Game** where users can pick **Heads** or **Tails** and test their luck!

---

## 🎮 **Features**

- Toss a virtual coin  
- **Heads / Tails** selection  
- Displays **Win**, **Lose**, or **Tie**  
- Real-time **Scoreboard**  
- Simple, beginner-friendly design
